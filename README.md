# 3D 国际象棋 · Chess 3D

一款使用 **Three.js** 打造的实时三维国际象棋游戏。棋子与棋盘全部由程序化几何体生成，无需任何外部模型与贴图资源；内置完整规则引擎、三档难度的 AI 对手与双人对战模式。

## 功能特性

- **完整规则**
  - 合法着法校验（绝对钉住、将军应对）
  - 王车易位、吃过路兵、兵升变（可选后 / 车 / 象 / 马）
  - 将死、逼和、50 回合规则、三次重复局面、子力不足和棋
  - 中文棋谱记录（含 `+` / `#` 标记）
- **人机对战**：Alpha-Beta 剪枝 + 静态搜索 + 局面评估表，AI 在 Web Worker 中运行，不阻塞渲染；三档难度
- **双人对战**：同一设备轮流走子
- **三维呈现**
  - 程序化车削 / 放样生成的立体棋子
  - PBR 材质、环境反射、实时软阴影、ACES 色调映射
  - 走子动画、马跳弧线、平滑视角切换
  - 吃子粉碎特效：棋子被击中后炸成有体积的碎石，配命中闪光、贴地尘埃、金色火花、镜头震动与分层打击音效
- **交互体验**
  - 点击选子 → 高亮合法落点（普通落点圆点、吃子红圈）
  - 上一步高亮、将军红色警示环
  - 悔棋、翻转视角、WebAudio 合成音效、移动端自适应布局
- **本地持久化**：对局模式、难度与音效开关会自动保存

## 快速开始

```bash
npm install
npm run dev      # 开发模式，默认 http://localhost:5173
npm run build    # 构建产物输出到 dist/
npm run preview  # 预览构建产物
```

浏览器需支持 **WebGL 2**（现代 Chrome / Edge / Firefox / Safari 均可）。

## 部署到 GitHub Pages

仓库已内置 `.github/workflows/deploy-pages.yml`：推送到 `main` 时会自动构建并发布静态站点。

首次发布需要先在仓库中开启 Pages：

1. 打开仓库 **Settings → Pages**
2. 在 **Build and deployment** 中把 **Source** 设为 **GitHub Actions**
3. 打开 **Actions** 页面，重新运行最新的 `Deploy to GitHub Pages` 工作流（或再推送一次提交）

发布地址：<https://renjiyige.github.io/ai/>

> 构建时默认基路径为 `/ai/`（与仓库名对应）。若仓库改名或绑定自定义域名，可在构建时设置 `BASE_PATH`，例如 `BASE_PATH=/ npm run build`。


## 实现说明

- 棋盘使用 64 长度的一维数组表示（`0 = a8`，`63 = h1`），棋子以 FEN 单字符存储。
- 规则引擎已通过 6 组标准 **perft** 测试（包含 Kiwipete、升变、吃过路兵、易位等局面）验证走法生成正确性。
- AI 评估由子力价值、棋子位置表、双象、叠兵、通路兵、残局王位置等构成；困难档使用迭代加深与 5 层搜索，并带时间上限。
- 棋子几何：兵 / 车 / 象 / 后 / 王 使用样条轮廓旋转体，马使用椭圆截面放样并附带耳朵、眼睛与鬃毛脊线。
- 吃子特效：棋子表面三角形按面积加权 Voronoi 聚成 18 块，每块把顶点连到中轴线后取凸包 —— 棋子是实心回转体，这样得到的是「从表面切到轴心」的楔形碎块，而不是一层薄壳；节奏为定格 50ms（碎片保持轮廓并发亮）→ 炸开 → 落桌弹跳 → 缩小淡出，同时叠加撞击核心、冲击波环、贴地尘埃、火星、全屏爆闪与沿撞击方向的镜头冲撞（推 FOV）。碎裂形状按「棋子类型 + 颜色」缓存，开场空闲预热，命中当帧约 1ms；系统开启「减弱动效」时退化为下沉淡出。

## 说明

- 本项目为纯前端应用，不需要后端服务，也不会发起任何网络请求。
- AI 为轻量级启发式搜索，难度可在「简单 / 中等 / 困难」之间切换，适合休闲对弈与练习；困难档单步思考时间上限约 5 秒。
